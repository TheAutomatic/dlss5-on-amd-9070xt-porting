## 候选（今天各轮没碰过、可能逐位；按收益×把握排）

1. **C512 QKV-attention 的 V 在 LDS 里转置存放（`C512_COMPACT_VT`）**：`c512_qkv_attention_compact` 的 P·V 每个 B 片段是 8 个 key × 1 个通道，现在从 [token][channel] 布局里逐字节取：每个查询 tile 64 条 `ds_load_u8` + 64 次字节插入（静态 ISA 64 条）。V（part 2）写 LDS 时改存 [channel][token]，读就是一条 8 字节读。同样字节、同样 WMMA 操作数，天然逐位；只换 c512-m32-mh 一个模块，宿主不动。两档都是前 4 的核（13 次/帧）。**止损**：静态 ds_load 不降或 900 三轮不全正就停。**本轮已做：逐位 19 组 SAME，静态 ds_load_u8 64→0，但三轮 900 −0.004/+0.000/+0.004、1080 +0.002/−0.002/−0.014ms，不全正，不收（`results/c512-compact-vt-20260930`）。**
2. **C256 的 W16 宽权重片段推广到 C64/C128（`c64/c128_wave2*`、`*_up`）**：`swin_wave2_body` 同一份代码，C64/C128 也走 QT batch（配方 `W2_FFN_QT_SMALL_MASK 3`、`W2_HIDDEN_TILES 2`），W16 那三处 `if constexpr(W16&&C==256)` 放宽到三种宽度即可，k 顺序不变→逐位。C64+C128 族 900 1.55ms / 1080 2.27ms，是 C256 持久化的 2.4 倍体量；C256 的 W16 在 ~0.7ms 上拿了 0.01～0.03ms，照比例估 0.02～0.05ms。要改宿主（新 `_w16` 导出存在才用，旧模块/旧宿主回退，照 c256-w16），add-on 与 RE9 runtime 都要重编。**止损**：静态 global_load 降不到 5% 或 900 ABBA 三轮不全正就停；不做 c64/c128 持久化（已交负账）。
3. **C512 AV 出口去 `F()`（`c5c_fp8(c5c_F(av))`→`c5c_fp8(av)`）**：F 与 fp8 都夹到 ±448，fp8(F(x)) 与 fp8(x) 只在 x=−0 时不同（F 给 +0）；av 是 FP8×FP8 WMMA 从 +0 累加，与 09-30 composite-quant 同一输入域，不产生 −0。每 tile 省 16 个 F（fmin/fmax/cvt_pk/cvt_f32/比较/选择）。QKV 那处 `q8(F(acc*inv))` **不做**（acc·inv 可下溢成 −0，域不纯）。**止损**：GPU 真指令穷举在域内有任何不同就停；收益小，可与 1 合并测。

已交负账没重复：C512 FFN M32/R/RF/LDS 共用、C64/C128 持久化、ViT attention 4wave 预取、字节尾巴全线（本地图上已无逐通道字节写出）。
