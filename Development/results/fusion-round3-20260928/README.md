## 数据与指令账

按一个有效8×8高分辨率窗口：低分辨率4×4像素、输入2C通道，投影为16×(2C)乘(2C)×C。
新核上采样新增WMMA：C32为8、C64为32、C128为128/窗口；首块原有矩阵工作另计。
旧路径执行同一低分辨率线性变换；未将静态ISA条数直接冒充动态矩阵工作。

|被移除的中间接口|原写＋后继读|每有效窗口逻辑字节|
|---|---|---:|
|C64 Up FP8→首块|64C＋64C|8192|
|C128 Up FP8→首块|64C＋64C|16384|
|C32 Up float→首块|256C＋256C|16384|

low输入与skip仍必须读取；新分组可能重复取数，移窗halo也需按实际grid计。
以上是中间tensor逻辑字节，不等于总VMEM请求下降，更不等于DRAM实测流量。
完整资源及口径在`ISA-UP.md`，不把这张字节表除峰值带宽作为提速证明。

## 独立筛选与拒收项

|候选|900短筛Δms|1080短筛Δms|决定|

|U2，两批|−0.0548 / −0.0463|−0.0312 / −0.0399|采用|

|P，投影顺带产下一块byte输入|+0.0669|+0.0053|拒收|
|G，再合入口Gather＋pack|+0.0628|+0.0176|拒收|
|Q，复用首次FP8编码并缩短byte引用寿命|+0.0231|+0.0106|拒收|
|R，后续对照变体|+0.0209|+0.0061|拒收|

P/G确实减少ViT pack派发，但投影多了byte出口与转换，不等于整个网络更快。
P的n64投影FP8编码32→64条，另加32条byte store；Q针对重复编码修剪后仍未兑现收益。
这几项保持为独立实验，最终ViT配方和入口Gather不改。

C32/ViT FFN没有新且足够小的复用切口：ViT M2/M4、平衡tile、布局/组重排已有试验；
C32跨qt共享需重构输入/FFN/QKV流水，并会延长寄存器活跃期。关闭依据见`ffn-audit.md`，不重跑旧失败形状。
