## 1. DLSS5_IO_FUSE=1（input-slim，results/input-slim-20261001）——不收

候选 = 同宿主 + `DLSS5_IO_FUSE=1` + assets-cand（decode shader A70789A1 带 `NATIVE_CODEC_NEURAL_BUFFER`；旧 shader 被宿主防呆拒绝，bitexact-pm G 已证）。

本轮现装基线重测（FULL_OK，SAME 18 行 + AE CSV SAME = 19 组，回绕过）：

## 2. C512_T8_NO_F32 1（gap-fusion，results/gap-fusion-20260930）——不收，宏已作废

- 该宏只删 `split_ffn_fused_fp8_t8` 里没人读的 f32 contract 写出（hip/deep_fast.hip:787）。
- 现装管线 C512 FFN 走 `split_ffn_one_w2f8`（c512-m32-deep 按配方 `C512_FFN_ONE 2` + `C512_FFN_F8W 1` 导出；host hip_reference_network.h:516 优先选它），`split_ffn_fused_fp8_t8` 只在模块缺导出时作回退——现装模块有导出，**该核每帧零派发**。
- 派发图实证（results/gap-map-evening-20261001，10-01 晚、同模块谱系，900/1152 两档）：每帧 13× `split_ffn_one_w2f8`，**0×** `split_ffn_fused_fp8_t8`。
- 结论：开 1 只是改掉一个死核的代码，运行时零差别，计时无可测。bitexact-pm §3 当时已记"作废"，本轮复查源码与派发图后终局确认。宏留源码默认 0（回退路径的历史开关），不进配方。
