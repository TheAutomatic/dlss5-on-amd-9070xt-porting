## Actual native/AMD primitive gates

The controlled24576 vectors (generated finite low/skip patterns through the real post operator, not real game frames) match the native5090 two-K16 HMMA gold bit for bit in both CPU aligned() and HIP implementations. Native65536 half-domain SIG versus AMD EXP2/RCP differs in11033 of63488 finite codes, max absolute1.1920929e-7/max3ULP; all2046 NaN codes differ in bit representation, infinities agree. The controlled24576 logits happen to have zero SIG differences; that subset does not prove the general or game domain. The strict path therefore takes the native scalar table, not AMD intrinsics disguised as exact.

The original-CUBIN16 post replay now has independent history/MV textures and observed Reset0 scalar packet layout (0x74 history6float /0x8c motion6float). Three zero-head cases (closed history, zero MV, +1 pixel MV) match the explicit FMA result with zero RGB float-bit differences. An additional(+.25,+.375) MV case is archived as native subpixel gold for the host warp test; no software sampler parity is assumed. These textures are self-created FLOAT4 with half-exact values, not a claim about the original API's private history texture format.

The sole resolve helper consumes raw five-tap RGB sum and reciprocal total weight in raw_warp.w, then forms delta in one FFMA and forms final RGB in one FFMA. The prefix's normalizedRGBA is a separate signal. Disabled history directly copies old RGB and does not evaluate an unusable history branch. Helpers/signatures are in gate_helpers.hip; GPU resolve/full MP1 sequence validation belongs to the next integration gate.
