# 默认配置换成"不跳块 + FAST_NUMERIC=1"的评估（2026-10-03，光派单，只测量，未改默认、未装机）

**结论先行**：提议的新默认 C（不跳块 + `DLSS5_FAST_NUMERIC=1`）比现默认 A（跳 42/43/46，=0）**慢** 900 **+0.12ms**（+1.7%）、1080 **+0.19ms**（+1.9%），p99 慢 0.23 / 0.19ms。换来的是对 NVIDIA 单帧 **+3.29 dB**（44.26→47.55）。三块本身的代价第一次单独量出来：900 +0.20ms、1080 +0.32ms；fast 数值抵回其中 0.08 / 0.13ms。

## 配置与方法

基线 = 剑星现装：宿主 benchmark-F（add-on 9D1FA493 那份宿主）+ 现装 gfx1201 模块（含两个 `-fast`，SUMS F3EFDC16）+ lab flags（`DLSS5_SKIP_BLOCKS=42,43,46`，FAST_NUMERIC 未设）。候选在 flags 末尾追加（后写的覆盖）。每组都和自己那一轮的 A 做 ABBA（1000 帧取 200 以后，默认静止序列，AE 关），三轮。

- A：现默认（跳 3 块，=0）
- B：`DLSS5_SKIP_BLOCKS=`（不跳块，=0）
- C：`DLSS5_SKIP_BLOCKS=` + `DLSS5_FAST_NUMERIC=1`
- D：`DLSS5_FAST_NUMERIC=1`（跳 3 块）

## 速度（相对 A，ms；`abba-B/C/D.txt`）

| 组 | 900 三轮 | 900 合并 avg / p99 | 1080 三轮 | 1080 合并 avg / p99 |
|---|---|---|---|---|
| B 不跳块 | +0.200 / +0.198 / +0.202 | 7.002→7.203 / 7.253→7.451 | +0.298 / +0.334 / +0.315 | 9.739→10.055 / 10.011→10.378 |
| **C 不跳块+fast** | +0.120 / +0.096 / +0.138 | 7.063→**7.181** / 7.297→7.526 | +0.184 / +0.190 / +0.186 | 9.777→**9.963** / 10.072→10.266 |
| D 跳块+fast | −0.007 / −0.117 / −0.106 | 7.080→7.004 / 7.348→7.256 | −0.095 / −0.103 / −0.098 | 9.781→9.682 / 10.057→9.981 |

三轮很稳（B、C 每档三轮极差 ≤0.04ms）。D 和 fast-numeric 那次测的 =1 单项（−0.07～−0.13 / −0.09～−0.10）一致。

## 画质

**对 NVIDIA**（fidelity-ngx，1080p 单帧，Style 0；四组都沿用 `fast-numeric-option-20261003/ngx-psnr.txt`，未重测）：

| A | B | C | D |
|---|---|---|---|
| 44.26 | 47.43 | **47.55** | 44.23 |

A 的偏色（mean_diff 0.148/0.228/−0.020）在 C 里回到 −0.013/0.047/0.104，与 B 同级。

**以 B（不跳块、逐位）为参考**，7 case × 12 帧（8-bit residual RGB ppm；`psnr-QA/QC/QD.txt`）：

| case | A 均值 / 最差 | C 均值 / 最差 | D 均值 / 最差 |
|---|---|---|---|
| 900-static | 51.25 / 51.25 | 54.10 / 54.10 | 50.49 / 50.49 |
| 900-motion | 51.19 / 50.83 | 54.16 / 53.47 | 50.17 / 49.32 |
| 1080-static | 50.90 / 50.90 | 54.16 / 54.16 | 50.36 / 50.36 |
| 1080-motion | 50.96 / 50.77 | 54.58 / 54.16 | 50.34 / 50.09 |
| 720-motion | 51.74 / 51.24 | 53.61 / **52.68** | 50.52 / 49.34 |
| 900-history | 51.91 / 51.25 | 55.88 / 54.10 | 51.68 / 50.49 |
| 1080-history | 51.38 / **50.69** | 56.01 / 54.16 | 51.04 / 50.36 |

运动 case 里：跳块偏 50.7～51.7 dB，fast 数值偏 52.7～54.6 dB——**fast 的偏差比跳块小约 3 dB**，最差帧 52.68（720-motion）对 50.69。两者叠加（D）再低约 0.5～1 dB。注意这个口径（residual RGB）下跳块只差到 51 dB，但在 NGX 整帧 sRGB 输出上它对 NVIDIA 掉 3.17 dB——跳块的误差方向是"离 NVIDIA 更远"的系统偏，fast 的误差与它正交（见 fast-numeric §3）。

## 一句话结论

C 相比 A **慢 0.12ms（900）/ 0.19ms（1080）**，对 NVIDIA **高 3.29 dB**（44.26→47.55），偏色消失；在运动 case 里 C 离逐位全算版比 A 近约 3 dB。

## 建议

换。用 ~1.8% 的帧时间换 3.3 dB 和偏色修正，比当初跳块"省 0.2～0.3ms 掉 3.17 dB"的交易划算得多；fast 数值的偏差在运动帧里也比跳块小。想要不慢，可以留 D 那种跳块档给追帧率的用户（D 比 A 还快 0.08～0.10ms），但默认应是 C。（未改默认、未装机，等 Zero 定。）
