## 激活：每个 x 从 WMMA 到下一次 WMMA 的字节输入

两边输入都是 f32 累加值 x。记 g=clamp(x,-4,4)，q=0.447265625−0.055908203125×abs(g)，p=0.89453125+g×q，最后量化 x×p。ACO 的 `NR_ACT_HORNER=1` 将 q、p 各自收缩成 FMA，我们保留每次乘、加的独立舍入。

下表按一个完整头 wave 的 256 个激活值计，使用**标量操作槽**。对应机器寄存器、汇编行号和循环倍数逐条列在 `lineup-ours.csv` / `lineup-aco.csv`。

| 数据流步骤 | C32 当前 | C64 当前 | ACO fswin32/64 | 多出部分的归属 |
|---|---:|---:|---:|---|
| x 的 NaN 规范化 `max x,x` | 256 | 0 | 0 | 编译器产物；ACT 只改激活 clamp 后删除 |
| g：clamp | 256 | 256 | 256 | 对应操作，med3 与 maxmin 的写法不同 |
| q：mul 然后 sub；ACO 一条 fma_mix | 512 | 512 | 256 | 语义必须：256 个独立舍入边界 |
| p：mul 然后 add；ACO 一条 fmaak | 512 | 512 | 256 | 语义必须：另 256 个独立舍入边界 |
| x×p | 256 | 256 | 256 | C64 用 fma(x,p,+0) 同时规范化负零，不能随便去掉 +0 |
| FP8 双值打包 | 128 | 128 | 128 | 已对齐，不再重复做 PACK8 |
| 打包前清零目的寄存器 | 0 | 64 | 0 | 编译器/内建函数产物，C32 的既有短 ASM 已消掉 |
| 合计 | 1920 | 1728 | 1152 | C32 多 768；C64 多 576 |

因此 C32 多出的槽位是 **语义 512、编译器 256、源码重复 0**；C64 是 **语义 512、编译器 64、源码重复 0**。折回发射指令，C32 chain 为 1280 对 910.5，C64 bi_bo 为 1392 对 909.5；差额不能直接等同标量槽差额，因为 VOPD 配对不同。

具体一值：我们的 C32 `v91 → max(v91,v91) 到 v99 → med3 → mul 到 v107 → sub → mul 到 v99 → add → v91×v99 → FP8`；C64 `v36 → med3 到 v44 → mul 到 v69 → sub → mul/add 到 v44 → fma(v36,v44,+0) → FP8`。ACO fswin64 对应 `%7510(v88) → %414(v48) maxmin → %418(v49) fma_mix → %421(v48) fmaak → %422(v88) mul → %432(v22)`。

不再尝试合并 q/p。已有 `c32-round2-20260927/fma-grid-cpu.txt` 的 2,097,153 个点积网格点反例：仅合 q 有 3 个 FP8 反例，仅合 p 有 66 个，两者合并 68 个。例如 x=-3.50050354，字节 0x94→0x95，绝非只有零符号。此证据也适用于相同多项式的 C64。

## softmax：固定求和以后到 FP8 概率

指数位图把单项限定到 [2^-14,9.75]，64 项和在 [1/256,624]。C32 按四个 K16 顺序做 WMMA；C64 保留原来的两侧交错 WMMA，再相加。ACO 是 packed-half 加法树、跨半 wave 交换、half clamp，再单条近似 rcp。它的求和精度/顺序和倒数都不同，不能替换我们的归约。

按完整 wave 的四个 query tile 计：

| 步骤（标量槽） | C32 | C64 | ACO | 判断 |
|---|---:|---:|---:|---|
| WMMA 后的分母合并 | 0 | 32 | 0 | C64 原有两侧和，必须保留 |
| packed-half 求和/交换/下限/转 f32 | 0 | 0 | 80 | ACO 独有路线；不能当成我们漏优化 |
| 倒数 | 160 | 352 | 4 | C32 是 rcp+两次误差修正；C64 还带通用除法的缩放/收尾 |
| exponent half→f32 | 128 | 0 | 0 | C64 已自动用 fma_mix；C32 有表示开销 |
| 乘倒数 | 128 | 128 | 128 | C64/ACO 的 fma_mix 已把 half 输入转换合进来 |
| FP8 打包 | 64 | 64 | 64 | 已对齐 |
| 常量/目的寄存器搬运 | 16 | 48 | 0 | 编译器产物 |
| 合计 | 496 | 624 | 276 | 发射指令为 468 / 572 / 276 |

倒数的槽位账：我们的布局每 wave 需 32 个标量结果，ACO 需 4 个，不能把 28 个直接当死代码。按原数值契约，32×(rcp+4 FMA)=160；相对 ACO 的 4 是 **156 个语义槽位**。C64 的通用除法另多 **192 个槽位**，是源码没有表达已知输入范围，可用已验证的有界倒数删掉。

三类归账（先列新增，再扣对方独有步骤）：C32 是语义 156、编译器 144（128 转换+16 搬运）、源码 0，扣 ACO 独有 80，净多 220；C64 是语义 188（156+两侧相加32）、编译器 48、源码 192，扣 ACO 独有 80，净多 348。没有将 WAIT 数当等待周期。

## 两个正式切口与两个 ISA 筛掉的写法

- **R / W2_BOUNDED_RCP**：只特化 C64～C256 wave 核的最终倒数。复用 C32 的 rcp+两次 FMA 误差修正，保留两侧和。该函数已有 gfx1201 全区间 144,441,345 个 f32 除数的逐位验证，本轮仍需整网 EXACT/AE。
- **ACT / CW_ACT_FMED3**：仅 FFN 激活的 clamp 显式写 fmed3。没有打开旧的全局 `CW_FMED3_CLAMP`，不碰 score clamp、输入 clamp、RGB clamp，也不改多项式。ACT 与 R 的组合叫 C。
- **M**：把 softmax 的 half 值先成对打包再用 fma_mix。额外拼接和零规范化抵掉收益；C32 chain 3781→3853，C64 bi_bo 5068→5336。EXACT 七组 84 帧虽逐位，ISA 门槛已失败，不升级到 AE/ABBA。
- **N**：去掉 M 的成对拼接，直接把单个 `_Float16` 送 inline ASM。C32 chain 仍 3813，mapped 4260，高于基线 3781/4232，止于 ISA。没有把未跑的回归写成通过。

| 核 | 基线普通向量/完整 wave | 正式候选 | VGPR 基线→候选 |
|---|---:|---:|---:|
| C32 chain | 3781 | ACT 3653 | 134→134 |
| C32 mapped | 4232 | ACT 4072 | 133→133 |
| C64 bi_bo | 5068 | R 4856 | 140→140 |
| C128 bi_bo | 5237 | R 5041 | 144→144 |
| C256 attn_bo | 1852 | R 1632 | 139→139 |

LDS 和 scratch 不变。用 metadata 的 `.vgpr_count`，不是硬件描述符中统一预留的 `next_free_vgpr=169`；详见 `resources.json`。默认宏均 0，没有新增运行时开关。
