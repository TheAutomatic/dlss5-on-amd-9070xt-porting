# DLSS5@AMD 0.41：近期更新与使用说明

0.41 三个完整包已发布。这次最值得试的是**快速 3x**：先真实跑两遍网络，再预测第三遍，省掉一遍完整计算。新安装仍默认 **1x**，不会直接把游戏切到三遍。

## 下载哪个包

夸克下载：https://pan.quark.cn/s/dbda3e470f8f

Gofile 镜像：https://gofile.io/d/YAENU0ex

两个地址提供相同的三个包：

| 文件名 | 适用情况 |
|---|---|
| `Magpie-DLSS5-AMD-0.41.zip` | 独立窗口缩放器；游戏不需要自己支持 DLSS 或 FSR |
| `OptiScaler-DLSS5-AMD-0.41.zip` | 常规游戏接入，例如《剑星》；仍需游戏接口与资源提交方式兼容 |
| `OptiScaler-REFramework-DLSS5-AMD-0.41.zip` | RE9 专用接入路线；已在《生化危机 9》《鬼武者：剑之道》验证，其他游戏不能保证 |

需要 Windows、AMD RDNA 4 显卡，以及带 `amdhip64_7.dll` 的 AMD 驱动，不用另外安装 HIP SDK 或开启开发人员模式。包内有 RX 9070 系列和 RX 9060 系列两套内核，自动选择；**本机实测是 RX 9070 XT，9060 系列已完成构建与包校验，尚待对应硬件反馈。** RX 7000 不适用。

## 相比 0.40 更新了什么

- **快速 3x**：选择三遍时，默认改为两遍真实网络加第三遍预测。预测会带来近似误差，可关闭。
- **接入修复**：修复快速 3x 首帧缓冲准备引发的卡死；提交网络任务时重新绑定选定的 HIP 设备，处理部分核显加独显机器的初始化后报错。常规包的前置路线增加自动判断，不符合提交条件时退到后置路线。
- **RE9 强度配置**：现在可在文件里设置亮度细节和色彩强度，覆盖宿主菜单；保留原来的自动模式。
- **计算与搬运优化**：减少多遍中间图拷贝、重复的字节解码和打包，改进 1440P 网络路径。多数是零点几毫秒的小收益，不能说整包会大幅提帧。默认快速数值路径还扩展到更多网络阶段，**1x/2x 也不与 0.40 默认输出逐位相同**。
- **可选肤色保护**：多遍时让肤色区域更多保留第一遍结果。它按颜色判断，可能误选暖色背景或漏掉彩色灯光下的皮肤；实玩收益不明显，默认关闭。

叠层、F9、三层配置、全 71 块默认和自由分辨率，**0.40 已经有了**。这次主要是在这些基础上继续提速与修接入。

## 安装与升级

**Magpie**：完整解压到独立目录，运行 `Magpie.exe`，游戏用窗口模式，选择包内 DLSS5 效果组。第一项 `FSR3_SR` 是网络入口，保持输入尺寸 1 倍；后面的 FSR4 负责放大。按 `Alt+Shift+A` 启停缩放。AMD 光流只在第一项用，后续 FSR4/XeSS 项的光流选 `None`。

**常规 OptiScaler**：退出游戏，备份实际游戏 EXE 旁的同名文件，把整包内容复制到 EXE 旁，包括 `DLSS5-AMD` 文件夹。《剑星》目录是 `SB\Binaries\Win64`，可按已验证设置使用 FSR3；其他游戏的 DLSS/FSR 输入选项，按包内说明及其支持路线设置。初次测试先关闭插帧。已有其他注入器或旧插件时，先按包内说明整理，避免重复加载。

**RE9 专用包**：退出游戏，按包内 `README.txt` 完整安装到实际游戏 EXE 旁，配套 `dxgi.dll`、`LmxxfNrRuntime.dll`、`dinput8.dll`、`DLSS5-AMD` 和 `shaders` 一起更新，不要与常规包混装。已有 `_storage_` 同名宿主/运行库时也要同步版本，移走旧后置网络插件以免重复处理。这个名字指接入路线，《鬼武者》也是走此路线。

从 0.40 升级仍需退出游戏后更新完整载荷。包会更新默认配置，但不覆盖已有的个人 `custom-config.txt` 和旧 `native-game-flags.txt`；升级前把这两个文件备份。Magpie 换独立目录时，需要自己带上原来的个人配置。

## 快速 3x 怎么开

这里的 1x/2x/3x 是**一帧经过网络的遍数**，不是超分倍率或插帧数量。

先在 `DLSS5-AMD` 下找 `custom-config.txt`。不存在时，把同目录的 `custom-config.template.txt` 复制一份并改名。自己的改动只写进 custom，**不要改随版本更新的 default 文件**。

想试快速 3x，写：

```ini
DLSS5_MULTI_PASS=3
DLSS5_MULTI_PASS_PREDICT=1
DLSS5_MULTI_PASS_SKIN_PROTECT=0
```

真实跑两遍，再按前两遍的局部变化预测第三遍。它接近的是本项目的真实三遍输出，**不保证等同真实 3x，更不能称 NVIDIA 原版逐位结果**；暗部、颜色、连续历史反馈仍可能有差别。

在同一个 3x 档对比真实三遍，只把预测行改为：

```ini
DLSS5_MULTI_PASS_PREDICT=0
```

真实三遍通常更慢。回到单遍，把 `DLSS5_MULTI_PASS` 改成 `1`。2x 仍是真实两遍，不受预测开关影响。

**《剑星》及适用的常规/Magpie 插件按 F9，在 1→2→3→1 之间切换。** F9 只切遍数，不切预测开关。配置热重载约一秒生效；RE9 runtime 路线没有 F9 或文件热重载，**《鬼武者》要改文件后重启游戏**。

本机已安装开发版的实玩读数：《剑星》1x 约 57.6 帧、快速 3x 约 37 帧；《鬼武者》900P 快速 3x 约 49 帧。这是该机对应场景的观察，不是不同游戏、显卡都能达到的帧率，也不是算子优化的统一增幅。

肤色保护可独立写 `DLSS5_MULTI_PASS_SKIN_PROTECT=1` 试验，只在多遍时生效。它会改变叠层观感；普通用户先保持 `0`。

## 强度与分辨率：别把几个“自动”混在一起

新版默认的常用设置是：

```ini
DLSS5_MULTI_PASS=1
DLSS5_MULTI_PASS_PREDICT=1
DLSS5_MULTI_PASS_SKIN_PROTECT=0
DLSS5_STRENGTH=auto
DLSS5_NETWORK_HEIGHT=auto
DLSS5_NETWORK_FREE_RES=0
```

预测默认 1，只在你选择 3x 时起作用。全 71 块与快速数值默认继续保留。

**强度必须写两个数**，前一个控制亮度转移/细节光照，后一个控制色彩混合。例如：

```ini
DLSS5_STRENGTH=0.7,0.3
```

常规插件和 Magpie 每项接受 0～3，1 是完整效果，超过 1 是外推，不建议作为日常起点；RE9 文件每项接受 0～1。单个数不会自动同时设置两项。强度不会减少网络计算量，设为零也不同于 F6 完整旁路。

常规/Magpie 的 `auto` 通常是 `1,1`，常规《赛博朋克 2077》是 `1,0`。RE9 的 `auto` 保留宿主/菜单明确指定的值，没有指定才用 `1,1`；有效文件数值会覆盖菜单。常规插件的强度可热重载，RE9 改文件需重启。

**网络档位不是游戏输出分辨率。** `DLSS5_NETWORK_HEIGHT=auto` 按送进来的图选 720/900/1080 档，两轴只比某档大 10% 以内时可缩进该档。例如 2K 输出、质量档输入约 1707×961，可以走 900 档，再由宿主放大到 2560×1440。强制写 `900` 是用计算尺寸换速度，也会改变画面。

默认 `DLSS5_NETWORK_FREE_RES=0`。超过 1080P 的输入可按默认适配策略缩进 1080 档，**不表示网络正在按原生 1440P 运算**。只有显式设为 `1`，才按输入本身尺寸加补边运行网络；原生 1440P、4K 更贵，且自由分辨率开关优先于固定档位。普通用户先保持自动分档和 `FREE_RES=0`。

常规包另有 `DLSS5_PRE_UPSCALE=auto`，判断网络应接在宿主放大之前还是之后；它与网络选档是两回事。Magpie 默认为 `0`，RE9 runtime 不读取这个键，不要互抄整套默认配置。

## 改了文件却没变化

配置优先级从低到高是：**default → custom → 旧 native → 进程已有的系统环境变量**。同一文件重复写同一键，最后一行为准。

最常见的情况是旧 `native-game-flags.txt` 仍写着同名项，盖住 custom。连 `DLSS5_STRENGTH=auto` 也会覆盖你在 custom 写的数值；删除或注释旧 native 中对应行再试。F9 会同步处理旧 native 的遍数行，但不会清理其他覆盖项。
